🎯 Jogo de Adivinhação

Um jogo simples e divertido desenvolvido com HTML, CSS e JavaScript, no qual o objetivo é descobrir um número secreto gerado aleatoriamente pelo sistema.

🎮 Sobre o projeto

O jogador precisa adivinhar um número entre 1 e 100. A cada tentativa, o jogo fornece uma dica informando se o número secreto é maior ou menor que o palpite realizado.

O objetivo é acertar o número utilizando o menor número possível de tentativas!

🚀 Tecnologias utilizadas
HTML5: estrutura da página.
CSS3: estilização e design da interface.
JavaScript: lógica do jogo e geração do número aleatório.
✨ Funcionalidades
Geração aleatória de um número secreto entre 1 e 100.
Verificação dos palpites do jogador.
Dicas indicando se o número secreto é maior ou menor.
Contador de tentativas.
Mensagem de vitória ao acertar o número.
Botão para reiniciar a partida.
🕹️ Como jogar
Abra o jogo no navegador.
Digite um número entre 1 e 100.
Clique no botão Adivinhar.
Siga as dicas apresentadas na tela.
Continue tentando até descobrir o número secreto!
Clique em Reiniciar para começar uma nova partida.
